1. Create a Promise that resolves with the message `"Welcome to Js Promise "` after 2 seconds.
2. Create a Promise that rejects with the message `"Invalid Data"` after 3 seconds.
3. Write a function `checkNumber(num)` that returns a Promise:
* Resolve if the number is Odd.
* Reject if the number is Even
4. Create a Promise that checks whether a person's age is greater than or equal to 18.
* Resolve with `"Eligible for Employement"`. * Reject with `"Not eligible for Employement"`.
5. Write a function `Sum(a, b)` using Promises.
* Resolve with the result of Sum. * Reject if `b` is `-value`.
6. Create a Promise that simulates ordering food:
* Display `"Order placed"`. * Resolve with `"Food is ready"` after 5 seconds.
7. Create a Promise that checks whether a string is empty.
* Resolve if the string contains characters. * Reject if the string is empty.
8. Write a function `findEven(num)` that returns a Promise:
* Resolve if the number is even. * Reject if the number is odd.
9. Create three Promises that resolve after 1 second, 2 seconds, and 3 seconds. Use `Promise.all()` to display all results.
10. Create three Promises where one Promise rejects. Use `Promise.race()` and observe which Promise completes first.
