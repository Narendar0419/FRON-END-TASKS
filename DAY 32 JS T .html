Destructuring Tasks 1. Create an array with five numbers and use array destructuring to store the first two numbers in separate variables.
2. Create an array of colors and use the rest operator to store the remaining colors in another array.
3. Create an object with properties `name`, `age`, and `city`. Use object destructuring to extract all values.
4. Create an object containing student details and rename the `name` property to `studentName` using destructuring.
--- Spread Operator Tasks
5. Create two arrays and merge them into a single array using the spread operator.
6. Create an array and add two new elements at the beginning and end using the spread operator.
7. Create an object with `name` and `age`, then create a new object by adding a `city` property using the spread operator.
--- Rest Operator Tasks 8. Create a function that accepts any number of arguments and returns their sum using the rest operator.
9. Create a function that accepts a name as the first argument and stores all remaining arguments in an array using the rest operator.
10. Create an array with six numbers. Use destructuring with the rest operator to store the first element in one variable and the remaining elements in another array.
